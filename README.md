\# Scapy HTTP Traffic Analysis and XSS Lab



\## Описание проекта



Лабораторная работа по анализу HTTP-трафика с использованием Python и Scapy на учебном приложении Google Gruyere.



\## Цели работы



\- Изучить структуру сетевых пакетов с помощью Scapy.

\- Перехватывать HTTP-трафик.

\- Анализировать HTTP GET-запросы и ответы сервера.

\- Изучать GET-параметры и HTTP-заголовки.

\- Анализировать HTML-содержимое HTTP-ответов.

\- Проверить обработку тестового XSS-пayload в собственной учебной среде.



\## Структура проекта



\- `scapy\_capture.py` — основной скрипт захвата и анализа HTTP-трафика.

\- `scapy\_capture\_backup.py` — резервная копия скрипта.

\- `report/xss\_analysis.txt` — результаты XSS-проверки.



\## Используемые технологии



\- Python 3

\- Scapy

\- Kali Linux

\- VirtualBox

\- Google Gruyere



\## Результаты



Был захвачен и проанализирован HTTP-трафик. Обнаружены GET-запросы, ответы сервера со статусами 200 и 302, а также заголовок Content-Encoding: gzip.



При тестировании XSS сервер изменил открывающий тег `<script>` на `<blocked>`. Выполнение JavaScript не подтверждено.



\## Примечание по безопасности



Работа выполнялась в собственной учебной среде. Исходные PCAP-файлы, содержащие данные сессии, не включены в публичный репозиторий.
